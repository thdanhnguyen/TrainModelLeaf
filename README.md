# TrainModelLeaf

A machine learning project for training models on leaf classification tasks.

## Overview

TrainModelLeaf is a data science project that focuses on building and training machine learning models for leaf classification. The project uses Jupyter Notebook for interactive development and experimentation.

## Project Structure

```
TrainModelLeaf/
├── train.ipynb          # Main training notebook
└── README.md            # This file
```

## Features

- Interactive model training using Jupyter Notebook
- Leaf classification using machine learning algorithms
- Experimental workflow for model development and evaluation

## Requirements

- Python 3.7+
- Jupyter Notebook
- Dependencies as specified in the training notebook

## Installation

1. Clone the repository:
```bash
git clone https://github.com/thdanhnguyen/TrainModelLeaf.git
cd TrainModelLeaf
```

2. Install required packages:
```bash
pip install jupyter
pip install scikit-learn pandas numpy matplotlib
```

## Usage

1. Launch Jupyter Notebook:
```bash
jupyter notebook
```

2. Open `train.ipynb` and run the cells to train the model
